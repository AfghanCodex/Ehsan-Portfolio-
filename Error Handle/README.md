# Ehsan Portfolio

A responsive personal portfolio for Ehsan Ullah, a software and web developer based in Afghanistan. Built with React and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Available commands

- `npm run dev` — start the local development server
- `npm run lint` — check the project with ESLint
- `npm run build` — create a production build in `dist`
- `npm run preview` — preview the production build locally

## Contact form

The contact form validates the visitor's details in the browser and opens their default email application with a prefilled message addressed to Ehsan. It does not submit data to a server.
